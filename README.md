# 📚 Digital Online Bookstore Platform

A web-based **Digital Online Bookstore Platform** developed using PHP, JavaScript, HTML, CSS, and MySQL. The system provides separate interfaces for customers and administrators to manage and operate an online bookstore efficiently.

## 📌 Project Overview

The Digital Online Bookstore Platform allows customers to browse books, view detailed information, add books to their shopping cart, place orders, and track their purchase history. Administrators can manage books, categories, inventory, customers, and orders through a dedicated admin interface.

This project was developed to gain practical experience in **full-stack web development, database design, authentication, e-commerce functionality, and user-friendly web application development**.
